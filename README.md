# Hyejin Kim - academic website

Source for [aadeliee22.github.io](https://aadeliee22.github.io/).

## Common updates

- Homepage: edit `index.html`.
- Research summaries: edit `_pages/research.md`.
- Publications: edit `_pages/publications.md`.
- Talks: edit `_pages/talks.md`.
- Short biography and education: edit `_pages/about.md`.
- Navigation, site title, and profile links: edit `_data/navigation.yml` and `_config.yml`.
- CV: replace `assets/files/CV_HyejinKim.pdf` while keeping the filename unchanged.
- Research figures: place web-ready PNG or JPG files in `assets/images/research/`.

Older blog posts remain in `_posts/` and appear through the research-notes archive at `/notes/`.
